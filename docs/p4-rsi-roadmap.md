- [x] 修复行动状态传播与 parser fallback 混杂；
- [x] 在公开环境预注册 discovery / hidden 边界；
- [x] 拒绝无效的“更长文字 Memory”候选；
- [x] 冻结显式状态控制器后进行一次 hidden 验证；
- [x] 发布脱敏聚合指标、可执行脚本、Markdown 报告与原创 SVG。

- [x] 在第二公开模型与互斥 `valid_unseen` 集复制正向结果。
- [x] 运行版本化的 failure-to-rule-to-Replay staging，并用第二个未接触窗口验证冻结候选。
- [x] 保留 P4-O/P 的 identity-rule 负结果：新鲜窗口无增益且跨 split 出现回退，候选被拒绝。

## 必须先做的确认实验

1. 扩展 P4-M/N staging candidate 的外部复现：新运行环境、更多模型族和预先固定的任务窗口。
2. 对每个自动候选坚持来源 replay、零重叠窗口、跨 split 三层门禁；来源失败改善不构成准入。
3. 将 P4-O/P 这类负结果纳入候选生成策略的停止条件，防止通过反复试探选择规则。

## 升级门槛

只有三项确认实验均通过，才可以讨论更大规模的 offline RSI prototype。即便如此，也不自动授权：

- 生产 Memory 写入；
- 训练标签生成；
- 真实业务系统动作。

这些授权需要各自独立的数据、风险、人工审核与发布流程。

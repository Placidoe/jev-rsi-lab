# Memory-RSI 实验协议

## 必须分离的阶段

1. **构建集**：从轨迹中产生候选经验；候选不等于 Memory。
2. **验证门**：独立模型只作为弱证据；最终要由确定性环境、单元测试或其他外部信号 Replay。
3. **staging Memory**：只允许在离线评测中检索，且每次命中后重新 Replay。
4. **冻结集**：不允许写入、调参、改模板或查看后再做选择。

## 公开归档规则

1. 只提交自主撰写的 Markdown、源码、合成输入、聚合指标和原创矢量图。
2. 外部公开基准在运行时按来源、版本和许可证获取；不把原始任务、完整轨迹、模型回答或上游
   代码镜像进仓库。
3. 私有人工审核、协作记录、工作簿、截图及任何可能包含个人标识的文件一律不提交。若实验有
   价值，只能用不含逐条样本的聚合报告说明设计、结论和排除理由。
4. 任何含本机绝对路径、访问令牌、账号、内部链接或未脱敏元数据的输出，必须先重写为可公开
   的摘要，不能直接复制。

## 报告必备指标

- baseline 与 Memory 版本的成功率；
- `errors_corrected` 与 `successes_regressed`；
- Memory hit rate；
- 错误候选率与最终不安全执行数；
- 构建/测试 template 家族是否隔离；
- 每条 Memory 的可追溯证据。
- 若基线被复用，必须声明；不得将后续局部干预与独立全量复现实验混为一谈。

## 不可越过的边界

- 两个或多个模型一致，仍不等于真值。
- 合成 oracle 证明的是合成环境中的机制，不等于现实业务的可用性。
- 未获授权的真实数据、策略和工具调用不属于本仓库实验范围。
